SWITCH / CONNECTION

Give the change a room.

Ripple sends requests through Switch. Your running agents inspect their workspaces and bring the results back.

The dispatch identity posts your requests. It is separate from the three agents doing the work. Its key stays in an ignored local file and is never sent back to this page.

Set up Switch for the first time
  1. Install Switch Console, start its local server, and choose Codex.
  2. Use switch/ripple.template.yaml in this project to create the three working agents and a real connected chat room.
  3. For one-click dispatch, follow switch/DIRECT-DISPATCH.md to register the dispatch identity. Use its agent ID and key here.
  4. Keep all three working sessions running. A successful connection test checks server access, not whether an agent is awake.

You can also use Manual handoff to copy the exact request into your real Switch room.
